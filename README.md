# Jodex Football Academy

This version uses the official Jodex Paystack Payment Page for donations:
https://paystack.shop/pay/gval0-m73r

No Paystack secret key or Vercel environment variable is required for the donation button.

Deploy the project root to Vercel. The Donate button opens the Paystack payment page in a new tab, where supporters can choose their donation amount and complete payment securely.
